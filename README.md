# 🌾 CropAlert — Monitor de Cultivos

## Descripción
Sistema que registra temperatura y humedad y determina el estado del cultivo.

## Estados
- ✅ **Normal** → Valores ideales
- ⚠️ **Atención** → Requiere seguimiento
- 🚨 **Crítico** → Actuar de inmediato

## Cómo usar
1. Copiar en `C:\xampp\htdocs\CropAlert`
2. Abrir: `http://localhost/CropAlert/`
